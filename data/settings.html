Analog RGBCCT white point

Use 6500K as the starting target for screen-matched white. Leave warm white at 0 if you want RGB + cold white only.

Feather softens the white-extraction edge above the threshold so slowly drifting near-neutral colors never jump between the RGB and white channels. 0 = hard edge (legacy).

Analog PWM quality

Gamma 2.2 maps the 16-bit pipeline onto the PWM perceptually — smooth dim scenes, no dark-end banding. 1.0 = legacy linear response (use this to keep an old calibration). Hardware dithering adds ~4 effective bits using the ESP32's fractional-duty dither at full PWM rate (invisible, flicker-free).
